Instructions

  1. Enter a nickname. Five papers will appear, randomized just for you.
  2. Each paper has three refined slide decks (System A, B, C). The mapping to underlying systems is hidden.
  3. Click the red Expand button to view a deck fullscreen (tabs let you switch between A/B/C).
  4. Below each deck is the list of goals it was refined against. For each goal, mark True if the deck satisfies it, False if not.
  5. Goals are grouped by category and differ across decks even for the same paper — that's expected.
  6. When every goal is answered, the Submit button enables.
